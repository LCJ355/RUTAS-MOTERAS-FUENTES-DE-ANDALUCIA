RUTAS MOTERAS - FUENTES DE ANDALUCIA
INSTRUCCIONES
============================================================

Esta es una aplicacion web de mapa interactivo solo online.
Abrela desde la URL publicada con un navegador actualizado.

Se necesita Internet para cargar los mapas y para consultar las APIs
de rutas (OSRM), elevacion (Open-Elevation), puntos de interes
(Overpass), meteorologia (Open-Meteo) y, cuando se usa, GitHub.


============================================================
COMO USAR LA WEB
============================================================

La web tiene 3 lineas de seleccion:

  1. SALIDA        - Pueblo donde empieza la ruta
  2. DESTINO       - Pueblo que quieres explorar
     (al seleccionarlo, se filtran las fuentes en mapa y lista)
  3. FINAL RUTA    - Pueblo donde termina la ruta

Planificar una ruta:
  1. Elige SALIDA, DESTINO y FINAL RUTA
  2. Pulsa en una fuente del mapa para ver detalles
  3. Pulsa "+" para anadirla como parada
  4. Pulsa "Calcular ruta"

Filtrar fuentes:
  - Selecciona provincia y pueblo en DESTINO
  - El mapa muestra solo las fuentes de ese pueblo
  - La lista lateral se actualiza automaticamente
  - El boton "Ajustar" centra el mapa en las fuentes visibles

Otras funciones:
  - Consultar clima y POIs con sus APIs online
  - Crear tramos manuales en el mapa
  - Importar y exportar GPX
  - Guardar/Cargar rutas
  - Compartir la ruta con Google Maps o WhatsApp
  - Elegir capas de mapa disponibles


============================================================
COMPARTIR FUENTES Y RUTAS
============================================================

Cada fuente tiene en su popup:
  - Maps: abre Google Maps con las coordenadas exactas
  - WhatsApp: comparte nombre, pueblo y coordenadas

Despues de calcular una ruta aparecen opciones para:
  - Google Maps: abre la ruta completa con todos los waypoints
  - WhatsApp: mensaje con inicio, paradas, destino,
    distancia, tiempo y enlace a Google Maps

Para actualizar:
  1. Revisa los cambios con Git
  2. Crea un commit y subelo al repositorio
  3. Espera al despliegue de GitHub Pages

Publicacion temporal desde el navegador:
  - Utiliza solo un token fine-grained limitado a este repositorio.
  - Concede unicamente el permiso de contenido necesario.
  - El token se conserva en sessionStorage y se elimina al cerrar la sesion.
  - Eliminalo tambien desde la interfaz al terminar.
  - No uses nunca un token clasico con permisos amplios.


============================================================
CARPETA DE DESARROLLO
============================================================

Los scripts y datos fuente estan en la carpeta:
  G:\-IA-\FUENTES-Access\

Pipeline actual:
  FUENTES_Andalucia.accdb -> export_rutas.py -> fuentes_data.js

export_rutas.py genera PROVS, TC, TP y FD directamente desde Access.
Despues se copia el fuentes_data.js generado a este proyecto y se
verifican los recuentos: FD 13,719, TC 712 y TP 711.


============================================================
NOTAS TECNICAS
============================================================

- Las coordenadas de las fuentes son reales (UTM ETRS89
  convertidas a WGS84 desde la DB de conocetusfuentes.com)
- Las preferencias, rutas y datos locales se almacenan en el navegador
- Las APIs publicas pueden registrar la IP segun sus propias politicas
- La aplicacion no ofrece funcionamiento offline
- Para compartir la web, publica los archivos mediante HTTPS

- Popups: fondo oscuro (#161b22), titulo dorado (#f5c842),
  marcadores azul fuerte (#1976d2)
- La disponibilidad y los limites de las APIs dependen de terceros
